Fleet & Army Names (Sequential)

Sequential Name Tip:
For Fleet and Army names, you can use special codes to generate sequences. This only works when using the localization file method, which this tool does automatically.
- $C$: Cardinal numbers (1, 2, 3...)
- $ORD$: Ordinal numbers (1st, 2nd, 3rd...)
- $R$: Roman numerals (I, II, III...)
- $HEX$: Hexadecimal numbers (001, 002, 003...)
One per line.
Use $ORD$ for ordinal numbers (e.g., $ORD$ Fleet becomes 1st Fleet, 2nd Fleet...).
