Aeronautica

Administrative Tools / Backend Developer

Train, Buy, Fly - Aeronautica is an open-world flight simulator with economy elements where the goal is entirely up to you. Earn money by completing unique jobs or flights between distant islands and continents. You can even create an airline for your friends to join! Train and earn licenses to unlock new exciting vehicles. Customize and maintain your planes as you work your way up from the smallest Ultralights to the world’s largest Airliners like the Airbus A380 Superjumbo.

TTMP 2

Sole Developer - Passion Project

TTMP (Tome Tales Management Panel) is a passion project I developed to streamline managing tabletop RPG sessions, specifically for Dungeons & Dragons. What started as a simple randomizer for enemies and locations grew into a comprehensive tool for game masters. It handles complex systems like currency tracking, loot box generation, and dynamic encounter creation. The front-end is built with HTML and styled with Tailwind CSS, while the core logic is powered by Lua running in the browser via the Fengari VM. This project was a fantastic learning experience in bridging different technologies to create a practical and fun application for my friends and me.
